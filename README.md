# TypePlay
TypePlay is a simple typing gmae made with react. it makes typing practice more interesting and fun.
Type the given words to help the character to jump to next platform and complete the level to reach higher levels and try to get the best score

## Features
- Typing game with multiple levels.
- 4 stages in each level.
- random English words at every stage.
- lives system for incorrect attempts.
- score calculation based on score and typing speed.

## Tech Stack
- react.js
- tailwindcss
- react-router
- random-words (to generate random words)

## Getting Started
clone the repository
```
git clone https://github.com/vaishali63-ig/TypePlay.git
```
go to the project directory
```
cd TypePlay
```
install dependencies
```
npm install
```
run project in development mode
```
npm run dev
```
Open the local url in yoour terminal to play the game.

## How to play
- Open the game and click on play.
- Target words will  appear on top.
- input words in the input box of the stag.
- press enter to submit your input.
- correct answer willmove the character to the next stage.
- incorrect answer will cost one life.
- complete all stages to reach next level.

---
TypePlay is made to improve typing speed and improve accuracy.
